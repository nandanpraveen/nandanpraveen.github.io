# TensorForge engineering report

TensorForge evaluates a configurable output-stationary systolic architecture for signed integer neural-network inference. The project includes SystemVerilog RTL, a bounded matrix interface, a cycle-accurate comparison against a sequential RTL MAC, coarse logic synthesis, and an interactive visualization of captured waveforms.

## Method and findings

The 2 × 2 configuration provided the shortest path to debug inter-PE propagation. The same PE was then elaborated through 16 × 16. A shared host protocol exercised the dimensions, loading sequence, busy-write behavior, tile boundaries, and result readback. All array configurations passed the same 35 cases, using temporaries and signed arithmetic independently generated by Python. Held-out Iris activities and logits passed the same interface and reference checks. The quantized classifier matched every floating-point prediction, with both making one classification error.

For the 32³ workload, throughput improved from 1.14 to 65.02 useful MACs per accelerator clock as PE count grew from 4 to 256. End-to-end accelerator utilization declined from 28.6% to 25.4% for that same workload. Small workloads lose more utilization because the valid front reaches only a portion of the array. The 16 × 16 version offers a cycle benefit for 32³ GEMM and no benefit over 8 × 8 on the measured 8³ GEMM. Host traffic can dominate even the 504-cycle 16 × 16 run because uploading both matrices and reading back C takes 3,072 scalar register transfers.

Coarse synthesis scaling follows PE and bank counts. The 8 × 8 version uses 64 multiplication operators and 25 memory objects, while the 16 × 16 version uses 256 operators and 49 memory objects. Timing closure, energy, and area depend on target memories and technology mapping. The design’s parallel scratchpad reads and output merge would be the main integration points to revisit for a physical target.
