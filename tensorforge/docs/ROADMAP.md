# Roadmap

| Milestone | Result |
| --- | --- |
| Architecture and toolchain | Implemented and documented a free Apple Silicon workflow and banked output-stationary architecture |
| Processing element | Verified signed MAC arithmetic and east/south propagation |
| Configurable systolic array | Validated 2 × 2, 4 × 4, 8 × 8, and 16 × 16 |
| Accelerator integration | Tested register protocol, banked storage, tiling and quantized writeback |
| Neural network inference | Trained and validated a quantized two-layer Iris network |
| Evaluation | Captured cycle counts, utilization, and coarse synthesis reports |
| Demonstration | Captured RTL traces, prepared the interactive demo, and wrote engineering, interview and portfolio materials |
| Optional extensions | AXI4-Lite, DMA, double buffering, convolution, alternative dataflows, and physical design |
