# Iris data

Fisher, R. (1936). Iris [Dataset]. UCI Machine Learning Repository. [DOI 10.24432/C56C76](https://doi.org/10.24432/C56C76). UCI makes the dataset available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

`iris.csv` is the corrected CSV redistributed by [scikit-learn](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/datasets/data/iris.csv). It encodes the labels as integers and includes a metadata row. TensorForge does not modify the dataset.
